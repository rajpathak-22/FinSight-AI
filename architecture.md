# FinSight AI — System Architecture

## 1. Overview

FinSight AI is a financial analytics and decision-support application built using Python and Streamlit.

The system processes uploaded financial data, performs analytical calculations, generates visualizations, applies forecasting and anomaly detection techniques, and uses a locally hosted Large Language Model to generate financial interpretations.

## 2. System Workflow

The overall workflow is:

User uploads Excel dataset  
↓  
Data ingestion and validation  
↓  
Financial calculations using Python and Pandas  
↓  
Analytics and analytical modules  
↓  
Interactive Streamlit dashboard  
↓  
AI-generated interpretation using Ollama  
↓  
Executive report generation in PDF format

## 3. Architecture Components

### Data Layer

The application accepts an Excel workbook containing financial information.

The demonstration dataset contains:

- Sales transactions
- Product information
- Customer information
- Expenses
- Receivables
- Monthly financial summaries

Pandas is used for data loading, transformation, aggregation, and analysis.

### Analytics Layer

Python performs the principal financial calculations, including:

- Revenue calculations
- Gross profit calculations
- Gross margin calculations
- Operating expense analysis
- Operating profit calculations
- Operating margin calculations
- Receivables analysis
- Expense reconciliation
- Financial anomaly detection
- Forecast generation
- Scenario modelling

### Visualization Layer

Streamlit provides the interactive user interface.

Plotly and Matplotlib are used to visualize financial performance, trends, forecasts, and scenarios.

### AI Layer

Ollama runs the Large Language Model locally.

The AI receives relevant financial metrics and analytical context generated by the Python application.

The AI is used for:

- Financial interpretation
- Natural-language question answering
- Executive summaries
- Management recommendations
- Report narratives

Python remains the authoritative source for numerical financial calculations.

### Reporting Layer

ReportLab is used to generate downloadable PDF executive reports.

Reports combine financial metrics, charts, forecasts, scenario results, analytical findings, and AI-generated narrative where enabled.

## 4. Technology Stack

| Component | Technology |
|---|---|
| Programming Language | Python |
| Application Framework | Streamlit |
| Data Processing | Pandas |
| Numerical Analysis | NumPy |

## 5. Design Principles

### Calculation-First Architecture

Financial calculations are performed programmatically before being supplied to the AI.

### Local AI Processing

The AI component is designed to run locally through Ollama, reducing dependency on external LLM APIs for the demonstration.

### Modular Analytics

The system separates financial analysis into distinct analytical functions and features.

### Transparency

Financial outputs, assumptions, anomaly flags, forecast errors, and scenario assumptions are presented to users.

### Human Oversight

AI-generated narratives and recommendations should be reviewed before being used for actual business decisions.

## 6. Limitations

- The dataset is synthetic.
- Forecasting performance depends on available historical observations.
- Scenario modelling uses simplified assumptions.
- Anomaly flags do not establish causation.
- Local AI functionality requires Ollama.
- AI-generated content may require human verification.
